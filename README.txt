RÉVEIL DES HÉROS II — META INTIMACY
===================================

Mini-site statique en une page, avec vos vraies photos déjà intégrées.

FICHIERS
- index.html : contenu du site
- styles.css : design + responsive + animations (thème vert 2026)
- script.js : animations au scroll + message aléatoire "Réveiller le héros"
- assets/ : photos (hero-bg, story, photo-1/2/3)

À MODIFIER
1. Dans index.html, remplacer les liens Instagram et TikTok par les comptes officiels.
2. Remplacer le lien "Partager mon expérience" (#) par votre Google Form / Microsoft Form.
3. Vous pouvez remplacer n'importe quelle photo dans assets/ en gardant le même nom de fichier.
4. Modifier les textes librement dans index.html.

MISE EN LIGNE
Vous pouvez déposer ce dossier directement sur Netlify, GitHub Pages ou Vercel.

Pour Netlify :
- Décompresser le ZIP
- Aller sur Netlify Drop
- Glisser le dossier meta-reveil-heros-2
- Une URL publique sera générée
- Utiliser cette URL pour créer le QR code
